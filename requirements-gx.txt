# Data-quality gates (src/quality.py, Great Expectations) — installed into their OWN virtualenv
# (.venv-gx), never the pipeline's .venv:
#   make gx-install   (or: python3.11 -m venv .venv-gx && .venv-gx/bin/pip install -r requirements-gx.txt)
#
# Why separate: importing Great Expectations in an environment that has pyspark pulls in Spark
# Connect, and PySpark 4.2.0's doctest heuristic there calls sys.exit(0) whenever the main module
# has no file (e.g. `python -c`): a validation process could end "successfully" without validating.
# The validator only reads files, so it needs neither pyspark nor the pipeline's other packages.
#
# Every package is pinned: this is the exact environment that was tested (pip freeze).
